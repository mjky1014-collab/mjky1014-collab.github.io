휴대폰으로
서브계정 만들기

실제 바이낸스 화면 사진에 빨간 동그라미를 그려 두었어요.
동그라미 친 곳만 순서대로 누르면 돼요.

✅ 본계정 KYC 완료면 바로 가능
🔢 일반 계정 최대 5개
💸 본계정↔서브 이체 수수료 0원

BEFORE YOU START시작 전 30초 점검

이 3개만 있으면 막히지 않아요.

🆔
본계정 KYC가 Verified 상태 → 서브계정은 인증을 또 하지 않아요.
🔐
2FA(Google OTP)가 켜져 있음 → 안 켜져 있으면 Sub Accounts 메뉴가 안 보여요.
📧
새 이메일 1개 → 바이낸스에 아직 가입 안 된 주소여야 해요.

STEP BY STEP따라 하기

1

앱 열고 왼쪽 위 프로필 누르기

○
Profile icon (top-left)

= 내 정보 버튼 (동그란 얼굴 아이콘)

👉 홈 화면 왼쪽 맨 위의 동그란 아이콘을 톡 누르세요. (보내주신 사진에서 표시하신 그 자리!)
💡 여기를 누르면 Personal Center(내 정보 화면)가 열려요.
2

Account Info 찾기

○
Account Info

= 계정 정보

👉 메뉴에서 Account Info 를 누르세요. (한국어 앱이면 계정 정보)
3

Sub Accounts 누르기

○
Sub Accounts

= 서브 계정

👉 Account Info 화면에서 Sub Accounts 를 누르세요.
⚠️ Sub Accounts 자체가 안 보이면 → 2FA가 꺼져 있거나 KYC가 아직 Verified가 아닌 상태예요.
4

Create Sub Account 누르기

○
+ Create Sub Account

= 새 서브 계정 만들기

👉 화면 오른쪽 위의 버튼을 누르세요.
5

만드는 방법 고르기

○
Sub Account Type

= 서브 계정 종류

👉 목록에서 Create with email 을 고르세요. (초보자는 이거 하나만!)
💡 Create with virtual email 은 앱 로그인이 안 되고 프로그램(API) 전용이라 초보자용이 아니에요. 3rd-Party Custodian 은 회사·기관용.
6

이메일 · 비밀번호 넣기

○
Email  ·  Password  ·  Confirm Password

= 이메일 · 비밀번호 · 비밀번호 확인

👉 Email : 새로 만든 이메일 주소
👉 Password : 서브계정 전용 새 비밀번호
👉 노란 Next / Create Sub Account 버튼 누르기
⚠️ 본계정 비밀번호를 여기에 쓰지 마세요. 서브계정은 따로 쓰는 새 비밀번호가 안전해요.
7

이메일 인증하기

○
Verify your email

= 이메일을 확인(인증)하세요

👉 서브계정에 넣은 이메일함 열기
👉 바이낸스 메일에서 Verify 버튼을 누르거나 6자리 숫자 입력
👉 메일이 안 보이면 스팸함도 확인
💡 여기까지 하면 서브계정 완성! 🎉 목록(Account Management)에 새 계정이 생겨요.
8

돈 옮기기 (필요할 때만)

○
Asset Management → Transfer

= 자산 관리 → 이체

👉 Asset Management 탭 → Transfer
👉 From(보내는 곳)= Main Account, To(받는 곳)= 새 서브계정
👉 코인·수량 입력 후 확인 (수수료 0원)
✓

만들어졌는지 확인

○
Switch Account → Sub Account

= 계정 전환 → 서브 계정 목록

👉 Profile → Account Info → Switch Account 를 열면 내 서브계정이 목록에 보여요.

ERRORS이 문장이 뜨면?

Please complete identity verification신분 인증을 끝내세요 → 본계정 KYC 확인
This email is already registered이미 가입된 이메일 → 다른 주소로
Enable 2FA first2단계 인증을 먼저 켜세요
Invalid verification code인증번호가 틀렸어요 → 새 코드 받기
Maximum number of sub-accounts reached더 못 만들어요 → 기존 정리 필요
Password does not meet requirements비밀번호가 너무 쉬워요 → 영문+숫자+기호

🔒 이건 꼭 지켜요

  • 비밀번호·OTP 숫자는 아무에게도 알려주지 않아요.
  • "서브계정 만들어 줄게" 링크는 100% 사기예요.
  • 주소창이 binance.com 인지 직접 확인하고 로그인해요.
  • 서브계정 이메일 비밀번호도 따로 관리해요.
  • 서브계정은 출금이 안 되고, 본계정에서만 자산을 옮길 수 있어요.
단계 제목을 누르면 체크되고, 맨 위 진행 바가 채워져요.
